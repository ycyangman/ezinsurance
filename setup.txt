CMD 창 띄워서 명령어 수행.
해당 소스폴더 위치 가서 (서비스 소스 있는 주소)
git init(초기화)
git remote add origin 깃허브URL주소  
git remote add origin "https://github.com/ycyangman/ezinsurance.git"

error: remote origin already exists.=>기존에 연결되어 있는 원격 저장소와의 연결을 끊음
git remote remove origin 

로컬 저장소를 원격 저장소에 연결
C:\MSA\ezinsurance>git remote -v
origin  https://github.com/ycyangman/ezinsurance.git (fetch)
origin  https://github.com/ycyangman/ezinsurance.git (push)

상태확인
git status

git add *(소스추가:or 파일명)
git commit -m "0.1"
git push -u origin master(깃허브에 올림)
-- ! [rejected]        master -> master (fetch first) 에러 나면 아래 명령어로 강제 push
git push origin +master

이전 로그인기록 있어서 커밋 안될때(초기화 하고 본인 깃허브 아이디 로그인)

git config --global user.email "ycyangman@gmail.com"
